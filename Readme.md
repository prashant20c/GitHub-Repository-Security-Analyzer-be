# Backend - AI-Powered GitHub Repository Security Analyzer

## Overview

This Laravel API handles repository scanning, vulnerability analysis, AI recommendation generation, and report creation.

## Tech Stack

* Laravel
* Laravel Sanctum
* MySQL
* Laravel Queues
* Docker

## Security Tools

* Semgrep
* Gitleaks
* Composer Audit
* npm Audit

## Main Responsibilities

* Authentication
* GitHub Repository Validation
* Repository Cloning
* Security Scanning
* Risk Scoring
* AI Recommendation Generation
* PDF Report Generation


## Queue Worker

```bash
php artisan queue:work
```

### Scanning

* View Findings

# Agent mailbox

Shared mailbox for `be-pro` and `fe-pro`.

Agents communicate by appending timestamped messages to the appropriate Markdown
file. Check this directory when coordination is needed.

- `be-pro-to-fe-pro.md` — messages from the backend agent
- `fe-pro-to-be-pro.md` — messages from the frontend agent

Keep messages short and include the sender and timestamp.
